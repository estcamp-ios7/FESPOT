# App project name
(ADS) 
- 타 지역 여행 시 이동 동선 내 축제·행사를 직접 찾아야 하는 시간적 부담과 최신 정보 수집의 번거로움을 해소하고, 남녀노소 누구나 지도 하나로 전국의 축제와 이벤트를 한눈에 확인할 수 있는 위치 기반 실시간 행사 가이드 서비스를 제공한다.

## Features
- 1
- 전국의 지도와 리스트로 정리된 각 지역별 현재 진행중인 축제 목록과 예정되어 있는 축제 목록을 한 눈에 볼 수 있는 가이드
- 2
- 위치 기반으로 주변의 축제 맞춤 알림
- 3
