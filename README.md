# FESPOT (페스팟)
(ADS) 
- 타 지역 여행 시 해당 지역 내 축제·행사를 직접 찾아야 하는 시간적 부담과 최신 정보 수집의 번거로움을 해소하고, 남녀노소 누구나 지도 하나로 전국의 축제와 이벤트를 한눈에 확인할 수 있는 위치 기반 실시간 행사 가이드 서비스를 제공하기 위한 앱입니다.

## Features
- 실시간 행사 지도
  - 사용자 현재 위치 기반 지도 표시
  - 지도 위 행사 위치 및 핀 표시
  - 행사 위치와 사용자 간 거리 확인
- 행사 검색 및 필터링
  - 행사명, 장소, 지역, 행사 종류 검색
  - 최근 검색어 저장 및 관리
  - 축제, 공연, 전시, 플리마켓, 먹거리, 야경, 체험 카테고리별 필터링
  - 날짜 및 시간별 행사 필터링
  - 현재 운영 중인 행사만 보기
- 지역별 행사 추천
  - 지역별 행사 목록 제공
  - 관심 카테고리 기반 맞춤형 추천
  - 관심도 및 최신순 정렬
- 행사 상세 정보
  - 행사명, 장소, 개최 기간 및 카테고리 확인
  - 행사 포스터 및 홍보 이미지 갤러리
  - 행사 소개 및 프로그램 정보
  - 운영 시간, 요금, 연락처 및 공식 홈페이지 확인
  - 사용자 현재 위치 기준 행사까지의 거리 확인
- 외부 지도 연동
  - 네이버 지도, 카카오맵, Apple 지도 연동
  - 행사 위치 기반 길찾기
  - 도보 및 자동차 이동 경로 지원
- 관심 행사 관리
  - 원하는 행사 찜하기 및 취소
  - 찜한 행사 목록 관리
  - 앱 재실행 후에도 찜 목록 유지
- 공공데이터 API 연동
  - 한국관광공사 TourAPI를 통한 축제 및 행사 정보 수집
  - 한국문화정보원 API를 통한 공연 및 전시 정보 수집
  - 행사 데이터 통합 관리
  - 주소가 없는 행사에 대한 지역 정보 추출
- 사용자 프로필
  - 닉네임 및 자기소개 설정
  - 거주 지역 설정
  - 관심 행사 카테고리 설정
